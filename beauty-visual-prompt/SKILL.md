# Beauty Visual Prompt

将一张或多张人像、美妆、时尚参考图转化为可复用的图像生成提示词。重点是“参考图里可观察到的视觉语言”，而不是评价人物或臆测人物属性。

## 何时使用

使用本技能处理：

- 从美妆、人像、时尚、广告、社交媒体风格图提取图生提示词
- 总结一组参考图的共同妆容、肤质表现、氛围、灯光和背景风格
- 为图生图、身份保持、换脸或批量素材生成准备统一提示词
- 将自然语言需求整理为颜值/美妆垂直的结构化 prompt

不要将本技能用于：

- 医疗、皮肤疾病、年龄、族裔或健康状况判断
- 身份验证、相似度认证或对真人“颜值”打分
- 根据脸部外观推断性格、收入、职业、性取向等不可观察属性

## 核心工作流

### 1. 确认输入图角色

对每张图标注角色：

- `style_reference`：提取妆容、质感、氛围、灯光和背景
- `identity_reference`：只用于保持人物身份，不把身份细节改写成文字猜测
- `target_image`：后续要被编辑或换脸的目标图

如果输入是本地图片，先使用可用的图像查看工具让图片进入视觉上下文，再分析；不要仅凭文件名猜测画面内容。

### 2. 逐图观察，再合并多图

先分别记录每张图的可见特征，再区分：

- `common_traits`：多张图稳定出现的风格，可放进主提示词
- `variable_traits`：角度、表情、发型、服装或场景变化，不应被错误地强行固定
- `uncertain_traits`：分辨率、遮挡或光线导致无法可靠判断的内容

多图输入时，优先提取共同视觉语言；不要把几十张图的所有元素堆进一个 prompt。

### 3. 按颜值垂直维度提取

至少覆盖以下维度；图中不可见的字段写“未观察到”，不要补写：

- 妆容：底妆妆效与遮瑕度、肤色呈现、腮红位置和色调、修容、高光、眉形、眼影、眼线、睫毛、唇妆
- 肤质表现：哑光/柔焦/自然纹理/水光，毛孔、细纹、雀斑或痘印等仅在清晰可见时描述；不做病理判断
- 头发与整理：发型轮廓、分缝、卷直、蓬松度、发丝光泽、是否有碎发
- 表情与气质：只使用可见的表情和画面氛围，例如冷静、柔和、编辑感、清透、慵懒；不要把氛围升级为性格判断
- 灯光：光源方向、软硬、色温、对比度、阴影、轮廓光、眼神光、反光关系
- 背景：颜色、材质、环境类型、层次、虚化、道具；不确定时使用“类似”而非具体地点
- 构图与摄影：景别、裁切、视角、主体位置、景深、摄影质感、画面比例
- 服装与配色：只描述与整体美妆视觉相关的可见颜色、材质和廓形

详细字段与词汇边界见 [references/beauty-visual-schema.md](references/beauty-visual-schema.md)。

### 4. 输出提示词

默认用中文输出，必要时附上英文关键词。输出顺序如下：

1. 一句话风格总结
2. 结构化视觉拆解
3. `主提示词`：可直接用于图像生成
4. `负面提示词`：控制常见伪影和风格偏差
5. `身份保持/换脸版提示词`：当用户明确要把模特放入参考风格时提供
6. `不确定项`：只列真正影响生成的模糊点

主提示词应描述场景与视觉风格，不应通过文字重新“定义”真人身份。身份由 `identity_reference` 图承担；如果是换脸任务，提示词只强调“只替换面部身份，保留目标图的姿势、发型、服装、背景、构图和光线”。

## 提示词写作规则

- 优先使用自然、连贯的摄影描述，不输出无意义的关键词堆。
- 先写最稳定、最重要的风格，再写细节；不确定内容使用“柔和的”“类似”“可见的”。
- 不虚构品牌、产品名、精确色号、镜头型号、地点或摄影师。
- 不把“皮肤纹理可见”写成皮肤问题；不把“年轻感”写成确定年龄。
- 参考图带有文字、logo或水印时，不把它们默认为生成需求，除非用户明确要求保留。
- 需要保持目标图时，重复“只改变指定部分，其余保持不变”这一不变量。
- 对批量任务，保持主提示词稳定，仅替换目标图、身份参考图或明确的场景变量。

## 默认输出模板

```markdown
### 风格总结
<一句话概括>

### 视觉拆解
- 妆容：
- 肤质表现：
- 头发与整理：
- 表情与氛围：
- 灯光：
- 背景：
- 构图与摄影：
- 服装与配色：
- 共同特征：
- 可变特征：

### 主提示词
<可直接复制的完整提示词>

### 负面提示词
<不需要的风格、伪影和错误>

### 身份保持/换脸版
<仅在用户需要时输出>

### 不确定项
- <仅列会影响生成的项目>
```
