# Beauty Visual Schema

本参考用于在需要时细化人像、美妆和时尚图的观察维度。只记录画面中可见、可合理描述的内容。

## 妆容

- 底妆：轻薄、自然肌理、柔焦、半哑光、奶油肌、光泽感、局部高光
- 遮瑕：低遮瑕、中等遮瑕、高遮瑕；仅描述视觉效果
- 腮红：位置（苹果肌、颧骨上方、横向晕染）、色调（蜜桃、玫瑰、裸粉、砖红）
- 眼妆：大地色、裸色、冷棕、金属感、细闪、晕染边界、眼线粗细、睫毛浓密度
- 眉妆：自然毛流、平直、柔和弧度、清晰眉峰、眉色深浅
- 唇妆：雾面、丝绒、润泽、玻璃唇、渐变、勾勒清晰度、可见色调

## 肤质与纹理

描述表面呈现：自然毛孔、细腻柔焦、局部油光、干净哑光、细小雀斑、可见细纹。不要将这些现象解释为疾病、年龄结论或健康结论。

## 氛围词

适合使用：清透、冷感、柔和、克制、浪漫、慵懒、编辑感、商业广告感、自然、亲密、电影感、极简、复古、梦幻。

避免使用：仅凭外貌推断的性格、道德品质、社会身份或心理状态。

## 灯光

记录：

- 方向：正面、侧面、侧上方、逆光、顶光
- 质量：柔光、硬光、漫射、强烈直射
- 色温：偏暖、偏冷、中性
- 关系：低对比、明暗分明、阴影柔和、轮廓光、发丝光、眼神光
- 反射：额头、鼻梁、颧骨、唇部等可见高光位置

## 背景与摄影

记录背景色、材质、景别、主体位置、景深、虚化强度、画幅方向和画面留白。除非参考图明确显示，不要虚构具体地点或设备型号。

## 多图合并规则

一组图中至少两张稳定出现的元素才可标记为“共同特征”。只在一张图出现的元素标记为“单图特征”，除非用户要求将它固定到所有生成结果中。角度、表情、发型和服装默认属于可变特征。
